Design Philosophy

Built the right way,
from day one.

  • DI-First Architecture

    One AddPrimitives*() call wires everything into your container. No static singletons, no hidden global state.

  • Layered Packages

    Core abstractions ship independently from transport integrations. Reference only what your project actually uses.

  • Extensible by Design

    Every behaviour surface is an interface. Swap, wrap, or extend any part without forking the source code.

  • Observable & Testable

    Structured logging, health checks, and in-memory test doubles ship in every core package — never as afterthoughts.

Principles

The Primitives contract

Every library in this collection is held to the same bar. No exceptions, no shortcuts.

01

Single Responsibility

Each library owns exactly one concern. Authentication authenticates. Caching caches. The scope never creeps.

02

Interface-Driven

Every behaviour is expressed as an interface. You own the implementation — we provide the wiring and sane defaults.

03

Zero Magic

No reflection tricks, no hidden global state. If you can read the code, you can understand what it does. Full stop.
